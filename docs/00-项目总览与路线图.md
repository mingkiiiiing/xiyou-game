# 项目总览与路线图

- **项目定名**：《造梦纪》，当前篇章「西游篇」——保留"造梦"意象致敬灵感来源但完全原创；后续可扩展「封神篇」「山海经篇」
- **项目定位**：2D 横版动作闯关 ARPG，玩法/系统/推进节奏对标《造梦西游4》，单人开发 + 多 AI 会话并行
- **平台**：PC 浏览器（本地 `npm run dev` 即玩），架构预留打包微信小游戏 / 桌面端
- **技术路线**：TypeScript + Vite + PixiJS v8，数据驱动（全部数值进 JSON 表），本地单机存档（localStorage）
- **合规红线**：《西游记》故事与角色是公版可自由使用，玩法模仿不受版权保护；但**不得使用** 4399 造梦西游的美术、音频、文案、数值表。所有素材一律自制 / AI 生成 / 可商用免费素材

## 核心玩法循环

> 选角 → 主城 → 选关卡 → 横版战斗（清波次 → Boss）→ 掉落装备/金币/经验 → 养成（升级/强化/宝石/技能）→ 解锁更难关卡（精英/噩梦）→ 循环

## 并行开发模型（多人员 = 多个 ZCode 会话/agent）

- 开发以「任务卡」为单位：`docs/tasks/TASK-*.md`，每张卡交给一个独立会话即可开工
- **TASK-A（框架）必须最先完成**——它定义所有接口契约，✅ 已于 2026-09-12 完成
- TASK-B~G 之间无文件依赖，可**同时**开多个会话并行执行
- 冲突规避手段（详见 docs/01）：目录隔离 + 契约冻结 + 演示场景自动发现（无中央登记文件）

## 立即体验

```bash
cd xiyou-game
npm install     # 首次
npm run dev     # 打开 http://localhost:5173
```

按键：A/D 移动，W/K 跳跃（二段跳），J 普攻三连，U/I/O 三个技能，Esc 暂停。
**BT-3 新增**：L/Shift 闪避翻滚（可取消攻击后摇），S/↓+J 下段扫击，空中+J 空中下劈，移动中+J 突进斩。
**BT-4 新增**：主城 B 养成面板（背包/装备/强化/宝石/技能），主城 V 商店，战斗 Q/E 红蓝药。
**BT-5 新增**：主城可选 3 角色（灵猴/蛮岩/云璿），选关页切换 普通/精英/噩梦 难度，第二章东海龙宫（2-1/2-2 长关卡）。
**BT-6 新增**：主城 宠物区（购买/出战）+ 日程面板（N：成就/日常领奖）+ 备份存档/导入存档。

演示场景（URL 加 `?scene=`）：
- `?scene=game` **集成主场景（推荐）** — 主城→选关→战斗→掉落拾取→结算→存档完整闭环，F1 无敌 / F2 增援
- `?scene=artreview` **美术总览** — 全部角色造型 × 状态切换 + 环境主题 + UI 组件
- `?scene=battle` M0 灰盒参考关
- `?scene=taskB` 新战斗角色（状态机/连段/手感）
- `?scene=taskC` 敌人波次 + 两阶段混世魔王（按 J 模拟玩家攻击）
- `?scene=taskE` 掉落→穿戴→强化→宝石全链路
- `?scene=taskF` 关卡流程与存档
- `?scene=taskG` 特效/飘字/震屏/程序化音效试炼场

测试与校验：
- `npm run verify` — 一键全量回归（数据 + 装备 81 + 战斗 49 + 经济 53 + 内容 55 + **宠物 43 + 服务 55** + 冒烟 78 + 压力 + 美术覆盖率）
- `npm run serve` — 本地试玩发布构建（dist/，端口 4173）；发布见 `docs/发布指南.md`
- `npm run sheet` — 生成美术联络表 `docs/preview/art-sheet.png`（角色×状态/环境/UI）
- `npm run frame` — 生成**战斗画面** `docs/preview/battle-frame.png`（无浏览器环境下的视觉联调）
- 单独：`npm run check-data` / `test-item` / `test-combat` / `smoke` / `stress` / `art-coverage`
