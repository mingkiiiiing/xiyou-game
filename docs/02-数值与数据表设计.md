# 数值与数据表设计（任务 D 的规格书）

原则：**全部数值进 `src/config/*.json`，代码零硬编码数值；一张表一个 schema；提供校验脚本。**

## 1. 战斗属性（BattleStats）

`hp / maxHp / mp / maxMp / atk / def / critRate(%) / critDmg(%) / moveSpeed`
预留扩展（M3+）：`hitRate / dodge / lifesteal / atkSpeed / damageReduce`

## 2. 核心公式（v1，全部可放 `config/formula.json` 调参）

- 浮动伤害：`raw = atk × 技能倍率 × (1 ± 5%)`
- 防御减伤：`最终 = raw × (1 - def / (def + 100 + 12 × 怪物等级))`
- 暴击：`× critDmg`（默认 150%）
- 回蓝：脱战 4/s（v1 简化为常回）
- 经验曲线：`expNeeded(lv) = 20 × lv^1.8`；每级成长：hp +8%、atk +6%、mp +5%
- 强化：+0~+15，每级 +8% 该装备基础属性；成功率 `[100,100,90,80,70,60,50,40,30,20,15,12,10,8,6]`；v1 失败不掉级（保底/幸运符后加）

## 3. 品质体系

| 品质 | 白 | 绿 | 蓝 | 紫 | 橙 | 红 |
|---|---|---|---|---|---|---|
| 词条数 | 0 | 1 | 2 | 3 | 4 | 5 |
| 基础属性倍率 | 1.0 | 1.15 | 1.3 | 1.5 | 1.8 | 2.2 |

掉落权重随关卡难度调整（普通关蓝装封顶，精英关出紫，噩梦出橙/红）。

## 4. 数据表清单（`src/config/`）

| 表 | schema 要点 |
|---|---|
| `player.json` | 初始 BattleStats + 每级成长率 |
| `formula.json` | 公式常量（variance/defenseK/defenseLevelFactor/mpRegen...） |
| `skills.json` | `{id,name,cdMs,mpCost,damageMul,hitbox{w,h,offsetX,offsetY,delayMs,activeMs},dashSpeed?}` |
| `monsters.json` | `{id,name,level,stats,aiType:melee\|ranged\|boss,attack{damageMul,range,cooldownMs},drops[]}` |
| `levels.json` | `{id,chapter,name,recLevel,waves[{monsterId,count,intervalMs}],bossId}` |
| `items.json` | `{id,name,slot,quality,baseStats,affixPool?}` |
| `strengthen.json` | 强化成功率表/加成系数/失败规则 |
| `gems.json` | 宝石等级/属性/镶嵌槽规则 |

## 5. M1 首版数值锚点

- 玩家 Lv1：hp100 / mp50 / atk10 / def5；普攻三连倍率 100/110/140%
- 技能：疾风突刺 150% CD3s 耗蓝10（带位移）；横扫千军 220% CD6s 耗蓝20；裂空跳劈 180% CD8s 耗蓝25
- 小怪：近战猴兵 Lv1 hp40 atk8；远程巫祝 Lv2 hp25 atk10；Boss 混世魔王 Lv5 hp800 atk15
- 节奏目标：第 1 关 3 分钟通关 → 升到 Lv3；Boss 战 1.5~2 分钟

## 6. 校验与平衡

- `npm run check-data`（scripts/validate-config.ts）：id 唯一 / 引用完整 / 数值范围 / 规模 sanity（≥2 近战、≥2 远程、≥1 Boss、≥30 件装备）
- 代码侧二次防线：`src/data/ConfigLoader.ts` 在模块加载时跑同一套 schema 校验（fail-fast）

## 附录 A. 战力曲线核对表

战力口径：`战力 = atk×10 + def×8 + maxHp + critRate×5`（仅裸身玩家，不含装备强化）。
成长：`base × (1+growth)^(lv-1)`，growth = hp 8% / mp 5% / atk 6% / def 4%。

| 等级 | maxHp | atk | def | 裸身战力 | 对应内容 |
|---|---|---|---|---|---|
| 1 | 100 | 10 | 5 | 280 | 1-1 林间道（recLevel 1） |
| 10 | 200 | 17 | 7 | 2530 | 第一章中段 |
| 20 | 432 | 30 | 11 | 4400 | 第一章末 Boss / 第二章开头 |
| 30 | 932 | 54 | 16 | 7660 | 第二章 |
| 40 | 2010 | 97 | 23 | 13940 | 第三章 |
| 50 | 4339 | 174 | 34 | 24770 | 第四章 |

章节推荐战力区间（怪物数值锚定，供新关卡设计时对照）：第一章 300~4500，第二章 4500~9000，第三章 9000~14000，第四章 14000~25000。
校准结论：以 Lv1 裸身 280 战力打 1-1（推荐 1）节奏约 3 分钟 ✓；若实测偏差 >20%，优先调 `config/formula.json` 与怪物 hp/atk，不改成长率。
