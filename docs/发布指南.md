# 发布指南（《造梦纪·西游篇》）

## 构建产物

```bash
npm run build     # 产出 dist/（纯静态，单页应用）
npm run serve     # 本地试玩构建版：http://localhost:4173
```

`dist/` 是**纯静态文件**（HTML + JS，无任何后端依赖），可部署到任何静态托管。

## 部署选项

### A. 腾讯云 CloudBase 静态托管（推荐，国内访问快）
1. `npx @cloudbase/cli@latest login`（或在 ZCode 中让 CloudBase MCP 走设备授权）
2. `npx @cloudbase/cli@latest hosting deploy dist -e <你的环境ID>`
3. 访问 `https://<环境ID>.tcloudbaseapp.com`

### B. GitHub Pages
1. `dist/` 内容推到 `gh-pages` 分支（注意：仓库需 Public 或启用 Pages 的私有方案）
2. Settings → Pages → 选分支

### C. 任意静态托管（Vercel / Netlify / 服务器 Nginx）
- 把 `dist/` 目录整体上传即可；单页应用无需特殊路由配置

### D. 微信小游戏（需要适配，见下）
- PixiJS 需要适配层（如 `pixi-wechat-adapter`），localStorage 需替换为 wx.storage
- 工作量预估：适配层 1~2 天 + 审核；列入后续计划

## 存档与数据

- 存档位置：浏览器 `localStorage['zaomengji_save_v1']`（JSON，版本号 2，含迁移逻辑）
- 备份：主城「备份存档」按钮 → 剪贴板 JSON（失败降级为下载文件）
- 恢复：主城「导入存档」→ 粘贴 JSON
